# API Marketplace

A modern API marketplace platform where developers can discover, try, and subscribe to APIs. API providers can publish and manage their APIs, set pricing plans, and track usage analytics.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS

## Features

- Browse and search APIs in a centralized catalog
- Interactive API documentation with try-it-out console
- API key management for developers
- Subscription plans and usage-based pricing
- Usage analytics and request tracking
- Separate dashboards for API consumers and providers

## Getting Started

### Prerequisites

- Node.js 18+ or Bun
- npm, yarn, pnpm, or bun

### Installation

Clone the repository:

```bash
git clone https://github.com/anhamern-blip/api-market.git
cd api-market/frontend
```
